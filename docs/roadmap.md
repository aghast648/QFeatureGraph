# Eight-Week Roadmap

| Week | Learning and implementation outcome | Completion evidence |
|---|---|---|
| 1 | Probability, entropy and reproducible experiment foundations | Splits, configuration loader and determinism tests |
| 2 | PyTorch baseline CNN and evaluation | Saved baseline checkpoints and shape/parameter tests |
| 3 | Activation capture and feature graph | Validated activation matrix, correlations and graph plots |
| 4 | Masking importance and exact fixed-k QUBO | Importance table and all-bitstring equivalence tests |
| 5 | Structural pruning and reconstruction | Masked/reconstructed equivalence and parameter reduction |
| 6 | QUBO-to-Ising mapping and ideal QAOA | Tested bit decoding, QAOA samples and exact objective gap |
| 7 | Repeated comparisons and interpretation | Three-seed baselines, stability, ablations and figures |
| 8 | Reproduction, documentation and release | Fresh-environment smoke run and curated results package |

The Notion project remains the task-status source of truth. GitHub is the source of truth for
specifications, implementation, tests, configurations, and experimental evidence.
